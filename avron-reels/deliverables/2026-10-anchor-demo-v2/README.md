# AVRON anchor demo V2: Fuel Gap in the reference look (2026-10-27)

The user asked for different motion graphics taken from their five reference videos ("any story would do"). This is the ~60 s Fuel Gap story (facts and estimates in `projects/2026-10-fuel-gap/research/sources.json`, the user's Tia Mirza VO in `public/fuel-gap/mix.wav`) rebuilt in that look. Code: `src/projects/anchor/ReelV2.tsx`, composition `AnchorDemoV2`.

## What comes from which reference
- **Paper collage (Pisa tower):** graph paper, a gold sun rising out of a grass strip, a cut-out object that leans. Here the object is a paper diesel pump that tilts and cracks as the loss is mentioned.
- **Grid tunnels (green and blue):** the Brent scene (blue) and the May price-hike scene (green), with lines moving toward camera. The house rule against grid floors is lifted for this reel only, because the user sent them as references.
- **Orbit squares and the motion-design board:** orbit rings with square nodes (freight ×8), two orbit dials (ICRA vs Jefferies), nested hexagons on a honeycomb panel (company / government / you), and the bead ring (right now / next).
- **Comic burst:** used once, for the −₹34 hit.
