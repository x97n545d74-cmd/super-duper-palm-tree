# Recurring cost estimate

Estimates as of November 2026 at roughly ₹85 per US dollar. **Check current prices on each provider's pricing page before committing**; plans and prices change.

| Item | Lean | Recommended | Notes |
|---|---|---|---|
| Hosting: Vercel | Pro, ~$20/month (≈ ₹1,700) | Pro, ~$20/month (≈ ₹1,700) | Vercel's free Hobby plan is for non-commercial use only, so a business site should use Pro. |
| Database, auth, storage: Supabase | Free (₹0) | Pro, ~$25/month (≈ ₹2,100) | Free covers this catalogue's size easily, but projects can pause when inactive and there are no automatic backups. Pro adds daily backups and no pausing. |
| Domain (.in or .com) | ≈ ₹700–1,200 / year | same | Renew yearly. |
| Google Business Profile, Search Console | ₹0 | ₹0 | |
| WhatsApp Business app | ₹0 | ₹0 | The website only opens chats; no WhatsApp API fees. |
| Email (optional, on your domain) | ₹0 (forwarding) | ≈ ₹150–250 per user / month | |
| **Approximate monthly total** | **≈ ₹1,800** | **≈ ₹3,900** | plus the domain once a year |

Not included: content work (product photos, data entry), legal review of the policies, and paid maintenance or support.

**Lower-cost alternative:** the site could be hosted on another Next.js-capable host with a free commercial tier. That would need small changes to deployment and isn't covered by this guide.
